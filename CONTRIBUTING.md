# Contribuindo

Este é um portfólio pessoal, mas a manutenção segue um fluxo simples:

1. Crie uma branch a partir de `main`.
2. Faça alterações pequenas e objetivas.
3. Rode `npm run lint`, `npm run typecheck` e `npm run build`.
4. Faça commit com uma mensagem clara.
5. Abra um Pull Request para `main` quando fizer sentido.

Nunca inclua tokens, senhas, chaves privadas ou arquivos `.env` reais no repositório.
